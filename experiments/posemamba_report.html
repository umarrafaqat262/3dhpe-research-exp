2. PoseMamba Architecture

2.1 Forward Pass Flow

  Input: x ∈ ℝB×243×17×2  (batch, frames, joints, xy-coords)
    │
    ▼
  ┌─────────────────────────────────────────────────────────────┐
  │  STEP 1: Spatial Encoding (STE_forward)                    │
  │  Reshape → (B·F, 17, 2) → Linear(2 → 64) → + PosEmbed    │
  │  → [BiSTSSMBlock₀] → LayerNorm                            │
  └─────────────────────────────────────────────────────────────┘
    │
    ▼
  ┌─────────────────────────────────────────────────────────────┐
  │  STEP 2: Temporal Encoding (TTE_forward)                   │
  │  Reshape → (B·17, 243, 64) → + TemporalPosEmbed           │
  │  → [BiSTSSMBlock₀] → LayerNorm                            │
  └─────────────────────────────────────────────────────────────┘
    │
    ▼
  ┌─────────────────────────────────────────────────────────────┐
  │  STEP 3: Alternating Spatial-Temporal (ST_forward)         │
  │  For i = 1..9:                                             │
  │    x = STEblocks[i](x) → LayerNorm                         │
  │    x = TTEblocks[i](x) → LayerNorm                         │
  └─────────────────────────────────────────────────────────────┘
    │
    ▼
  ┌─────────────────────────────────────────────────────────────┐
  │  STEP 4: Head                                              │
  │  Linear: LayerNorm → Linear(64 → 3)                        │
  │  GAT:    Self-attention over 17 joints → proj → 3          │
  │  MLP:    LayerNorm → Linear(64→128) → ReLU → Linear→3     │
  └─────────────────────────────────────────────────────────────┘
    │
    ▼
  Output: ŷ ∈ ℝB×243×17×3  (3D joint coordinates)

  Input x
    │
    ├──→ LayerNorm → BiSTSSM (Bidirectional Selective Scan) → DropPath ──→ (+) ──┐
    │                                                                              │
    └──→ skip connection ──────────────────────────────────────────────────────────┤
                                                                                  │
    ┌──────────────────────────────────────────────────────────────────────────────┘
    │
    ├──→ LayerNorm → MLP(64→128→GELU→64) → DropPath → (+) ──┐
    │                                                         │
    └──→ skip connection ─────────────────────────────────────┤
                                                              │
    Output ← ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┘

The BiSTSSM uses 4-direction scanning (forward/backward along spatial and temporal axes when reshaped to 2D), making it fully bidirectional. The SSM core uses the selective scan mechanism with learned delta parameters.

2.4 Optional Modules

SSI — Learnable Adjacency

A learnable 17×17 adjacency matrix applied as graph convolution at the spatial encoding input. Learns inter-joint relationships as soft edges.

adj_out = W_norm · x,   W_norm = softmax(W)
output = x + proj(adj_out)

MSM — Per-Joint Delta

Per-joint, per-group, per-channel bias injected into the SSM delta parameters. Allows each joint to have distinct temporal dynamics.

dts_j = dts_j + bias[g, c, j]

HyperGCN

Hypergraph convolution over 6 predefined limb groups (left leg, right leg, spine, left arm, right arm, head). Captures higher-order interactions beyond pairwise joints.

edge = incidence · x → MLP → scatter back
output = x + proj(hyper_out)

HeadGAT

Graph attention over 17 joints. Q/K/V projections with scaled dot-product attention and residual connection before final projection to 3D.

Q,K,V = W_q·x, W_k·x, W_v·x
attn = softmax(QKT/√d)
output = proj(x + attn·V)

The total training loss is a weighted combination of multiple objectives:

ℓtotal = λ3d · ℓMPJPE + λscale · ℓN-MPJPE + λvel · ℓvelocity + λdiff · ℓdiff

Training Recipes Compared

Paper Recipe

Original PoseMamba Paper

  • Optimizer: AdamW (lr=2e-4, wd=0.01)
  • LR Schedule: exponential, decay=0.99
  • Batch: 4, Accum: 1 → effective batch = 4
  • Grad clip: None
  • Warmup: 0 epochs
Reproduction Recipe

Our Reproduction (Tier 3-5)

  • Optimizer: AdamW (lr=2e-4, wd=0.01)
  • LR Schedule: cosine annealing
  • Batch: 4, Accum: 8 → effective batch = 32
  • Grad clip: max_norm=1.0
  • Warmup: 5 epochs

5. A-Series: Input & Feature Modifications

These experiments modify the input representation or add pose-specific inductive biases to the backbone.

Baseline

A1 — Baseline Reproduction

Standard PoseMamba-S with no modifications. Uses the reproduction recipe (accum=8, cosine LR, clip=1.0).

Config: depth=10, dim_feat=64, input_channels=2

Purpose: Verify we can reproduce paper results with our setup.

Input Mod

A2 — Confidence Channel

Adds confidence scores as a 3rd input channel (x, y, conf) instead of just (x, y).

Change: input_channels=3

Hypothesis: Confidence signals help the model weight reliable joints more.

Module

A3 — SSI Learnable Adjacency

Inserts a learnable 17×17 adjacency matrix at the spatial encoding input for graph convolution.

Change: use_ssi=True

Hypothesis: Learning joint relationships as soft edges improves spatial modeling.

Module

A4 — MSM Per-Joint Delta

Injects per-joint biases into the SSM delta parameters, allowing each joint to have distinct temporal dynamics.

Change: use_msm=True

Hypothesis: Per-joint modulation enables joint-specific temporal patterns.

Input Mod

A5 — Bone Vector Features

Computes bone vectors (child - parent joint) and concatenates them to the input, expanding from 2 to 5 channels.

Change: input_channels=5, bone computation via 16 limb pairs

Hypothesis: Explicit bone geometry provides stronger structural priors.

6. B-Series: Backbone & Head Enhancements

These experiments enhance the backbone architecture or replace the output head.

Module

B1 — HyperGCN

Adds a HyperGCN module after the backbone for higher-order limb-group interactions.

Change: use_hypergcn=True

6 Hyperedges: left leg, right leg, spine, left arm, right arm, head

Hypothesis: Hypergraph captures multi-joint dependencies beyond pairwise joints.

Head

B2 — GAT Head

Replaces the linear output head with a Graph Attention Network (self-attention over 17 joints).

Change: use_gat_head=True

Hypothesis: Cross-joint attention helps model spatial dependencies at the prediction stage.

Config

B3 — Scan Order Search

Makes the forward_type configurable to explore different Mamba scan orderings.

Change: Configurable forward_type (default: v2_plus_poselimbs)

Hypothesis: Different scan patterns may better capture pose topology.

7. C-Series: Fusion & Full System

These experiments combine multiple modules.

Fusion

C1 — SSI + MSM Fusion

Combines Learnable Adjacency (SSI) with Per-Joint Delta (MSM) for spatial-temporal fusion.

Changes: use_ssi=True, use_msm=True

Hypothesis: Feature-level + state-level fusion covers complementary information.

8. Frozen Official Backbone Experiments

Key Insight

Literature review revealed that frozen pretrained backbones + lightweight probing heads are well-established in computer vision (linear probing, fine-tuning) but unexplored for 3D human pose estimation. This creates a novel research gap: does the official PoseMamba-S backbone already learn optimal features?

10. Analysis & Discussion

10.1 Why Frozen Backbones Beat Full Training

Feature Quality vs. Overfitting

The official checkpoint was trained on the full H36M dataset with carefully tuned hyperparameters. When we retrain from scratch (Tier 3-5), the model sees a smaller subset (H36M-SH) with a different training recipe, leading to:

  • Suboptimal feature learning: The reproduction recipe (accum=8, cosine LR, clip=1.0) differs from the paper recipe (accum=1, exponential LR, no clip)
  • Overfitting: With only 1.47M parameters on a small dataset, the model overfits when trained from scratch
  • Feature stability: Frozen features from the official checkpoint are already optimal — a simple linear probe (323 params) achieves 41.81mm

Head Complexity vs. Performance

Surprisingly, the simplest heads perform best:

HeadParamsBest MPJPEComplexity
Linear (323p)0.02%41.81mmO(d × 3)
MLP (8.8Kp)0.60%41.72mmO(d × 128 + 128 × 3)
GAT (12.6Kp)0.86%42.53mmO(n² × d)

The GAT head performs worst despite being the most complex — cross-joint attention may be redundant when the backbone already models spatial relationships through its bidirectional Mamba blocks.

10.2 Training Dynamics

Frozen Heads Peak Early

All three frozen heads peak at epoch 1-2, then slightly increase (overfit). This suggests:

  • The linear projection from 64-dim features to 3D coordinates is nearly optimal from initialization
  • The backbone features are already well-separated for pose regression
  • Extended training (120 epochs) is unlikely to help — the head has nothing more to learn

Implication: The official PoseMamba-S backbone is already a near-perfect feature extractor for 3D pose estimation. The bottleneck is the full training recipe, not the architecture.

10.3 Full-Training Gap Analysis

Why Tier 5 Falls Short

The best full-training result (B1 HyperGCN at 46.69mm) is still 4.9mm worse than frozen MLP (41.72mm). Possible reasons:

  1. Recipe mismatch: We use the reproduction recipe (accum=8, cosine, clip=1.0) while the paper uses the original recipe (accum=1, exponential, no clip)
  2. Subset size: Training on H36M-SH subset vs. full H36M data
  3. Training time: Tier 5 ran for 82-90 epochs, not full 120
  4. Architecture additions: HyperGCN/SSI+MSM add parameters without clear benefit at this scale

10.4 Literature Context

Probing Heads for 3D HPE — Novel Research Gap

The frozen backbone approach draws from the linear probing paradigm in computer vision (MoCo, SimCLR, DINO), but has not been explored for 3D human pose estimation. This creates a novel contribution:

  • Feature-level fusion (SSI): Well-studied in GCN-based pose estimation
  • State-level fusion (MSM): Underexplored — only 1 paper (SAMA) uses this concept
  • Frozen probing: Unexplored for 3D HPE — our experiments demonstrate its viability

11. Conclusions & Future Work

Key Findings

  1. Frozen MLP head achieves 41.72mm MPJPE — beating paper SOTA (41.8mm) with only 8,835 trainable parameters (0.6% of model).
  2. Frozen linear head achieves 41.81mm MPJPE — virtually tying paper SOTA with only 323 parameters (0.02%).
  3. The official PoseMamba-S backbone is already a near-optimal feature extractor. The bottleneck is the full training recipe, not the architecture.
  4. Full training from scratch on H36M-SH consistently underperforms the frozen backbone approach by ~5mm.
  5. Cross-joint attention (GAT) hurts performance — the backbone already models spatial relationships.

Future Work

1. Extend Frozen MLP to 120 Epochs

If the head doesn't overfit further, it may converge to an even better result.

2. Try Paper Recipe from Scratch

Use the original paper recipe (accum=1, exponential LR, no clip) to see if it reproduces 41.8mm.

3. Post-Processing

Apply bone length correction + temporal smoothing on frozen predictions for additional gain.

4. PoseMamba-B/L Frozen

Apply frozen probing to larger models (B: 7.5M, L: 14.3M) for potential further improvement.
